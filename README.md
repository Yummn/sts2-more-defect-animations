# 更多机器人动画（独立手机版）

版本：0.15.1；适用：杀戮尖塔 2 Android v0.111.0。

本包将 Steam 创意工坊 `More Defect Animations | 更多机器人动画`（Workshop ID `3810696310`，原作者 page，原版本 v0.15.0）移植为独立手机版安装包。

## 功能

为以下故障机器人卡牌添加视觉效果，玩法数值、目标、费用、等待和原生卡牌结算保持游戏原版：

- 冷静头脑、充电、偏差、热修复、信号增强
- 缓冲、超临界态、碎片整理、模组改造
- 散射炮、暴涨、全息影像、冰枪、编译冲击、污秽攻击
- 双重释放、四重释放、多重释放、融入暗影

## 独立性

- 不依赖 BaseLib、RitsuLib、JmcModLib 或 BetterDefect。
- 包内只保留主程序集、动画资源、本地化文件和安装说明；创意工坊附带的可选设置菜单程序集已移除。
- 没有设置菜单库时，原 Mod 的默认行为是全部动画启用。
- 如果旧的 `MoreDefectAnimations` 已安装，只保留本包一份，避免 Harmony 补丁重复加载。

## 安装

1. 解压本 ZIP。
2. 将解压得到的 `MoreDefectAnimations` 文件夹复制到游戏的 `mods` 文件夹。
3. 在游戏 Mod 列表启用“更多机器人动画（独立手机版）”。
4. 完全退出并重新启动游戏。

Android 具体 `mods` 路径取决于启动器的存储映射；应复制到启动器实际显示的游戏 `mods` 目录，不要把 DLL 单独放在 Android/data 根目录。

## 资源与许可说明

动画 DLL、PNG/WAV/场景/着色器及本地化资源来自 Workshop ID `3810696310` 的原始包。本包只做手机版目录裁剪、Manifest 标注和独立性处理；原作者与原资源版权归原作者及其许可范围所有。

## 已知限制

本包不包含可选的设置界面，因此不能在游戏内逐项关闭动画。需要关闭时应停用整个 Mod。替换故障机器人身体的皮肤可能使依赖原始骨骼的效果无法显示；独立效果仍可正常工作。
